`check-live.mjs` performs only public reads and saves bounded evidence. The mock wallet answers account/network reads for a public dummy recipient; signing and authorization methods throw. No protocol address is registered.

`register-lombard-test-address.mjs` is a separately authorized test-only operator tool. After building this package, set `BITCOIN_TESTNET_WALLET_FILE` to the existing isolated credential file documented in the private operator notes, then run the script. It checks file permissions, testnet-only metadata, the public Sepolia chain, and the exact EIP-712 domain before a local fee authorization. It cannot broadcast Bitcoin or Ethereum transactions. Its report contains only public identity, quote, result and counts; no keys or signature bytes. Current sandbox status is incomplete, so the final recorded run blocks before requesting a signature.

Any funded lifecycle runner must use a new dedicated testnet identity, validate chain identity before each submission, keep keys outside this repository with directory mode 0700 and file mode 0600, and record confirmed transaction IDs. A faucet CAPTCHA or account requirement must not be bypassed. Do not use existing user wallets or real Bitcoin.
